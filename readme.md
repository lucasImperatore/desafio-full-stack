# 📚 BookMark

Projeto web para gerenciamento de livros, desenvolvido com **Node.js**, **Express**, **HTML**, **CSS** e **JavaScript**, utilizando banco de dados relacional.

---

## 🚀 Funcionalidades

- Listar livros cadastrados
- Cadastrar novos livros
- Deletar livros cadastrados
- Atualizar notas e status de livros ja cadastrados
- Interface web simples e responsiva
- Comunicação entre front-end e back-end
- Persistência de dados em banco de dados

---

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express
- HTML5
- CSS3
- JavaScript
- SQL (MySQL / MariaDB ou similar)
- npm
